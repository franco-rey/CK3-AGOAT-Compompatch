AGOT - Mega Wars Revolt Succession Fix 1.1.0
================================================

This local mod is already installed in the Crusader Kings III local mod folder.

In the Paradox launcher:
1. Add/enable "AGOT - Mega Wars Revolt Succession Fix" in the AGOT playset.
2. Place it after "A Game of Thrones", "More Interactive Vassals", and
   "MIV - AGOT CB Compatibility".
3. Keep "AGOT OPB Addon Compatibility" as the final playset entry.

Target versions:
- Crusader Kings III 1.19.0.6
- A Game of Thrones 0.5.1
- More Interactive Vassals 4.0

Version 1.0.0 behavior retained:
- Defers punishment after future agot_revolt_war defeats so realm restoration
  completes before execution and succession.

Version 1.1.0 behavior added:
- Routes agot_rebellion_war victories through a patch-owned synchronous copy of
  the AGOT crown-choice chain.
- Shows "Take the crown for yourself" before "Depose".
- Requires a human winner to confirm that Depose uses ordinary succession and
  installs the defeated ruler's heir. AI behavior and weights are unchanged.

This patch is prospective. It does not repair old saves whose succession has
already resolved. Rebase both keyed CB overrides and the local crown-event chain
before using the patch with a later AGOT version.

Do not edit Workshop content, launcher databases, dlc_load.json, or live saves.
