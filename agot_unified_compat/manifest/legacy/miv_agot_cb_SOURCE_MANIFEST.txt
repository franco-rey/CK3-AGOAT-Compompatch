Patch scope
- 16 substitutions across the three files above.
- Each invalid MIV `using_cb` condition referencing an AGOT-disabled casus belli
  is replaced by `always = no`, preserving its surrounding OR/NOR structure.
- Disabled identifiers: populist_war, minor_religious_war, religious_war,
  major_religious_war, undirected_great_holy_war, directed_great_holy_war.
- No Workshop file, save, playset, or launcher database is modified by this mod.

Update warning
These are complete-file overrides. Disable this patch and re-audit it after any
AGOT or More Interactive Vassals update so upstream changes are not masked.
